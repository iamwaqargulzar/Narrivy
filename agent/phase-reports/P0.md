## Deviations / ADRs
- **Manifest scripts patched** (deviation from v0.3 pack, not an ADR but documented here):
  - `scripts/build_manifest.py` and `scripts/verify_manifest.py` previously included `target/` in manifest enumeration, causing validation to fail after any cargo build and after Cargo.lock generation. Updated both to exclude `target`, `node_modules`, `dist`, `.vite`, `__pycache__`, `.pytest_cache`, `artifacts` (mirroring .gitignore intent). Regenerated `BUILD-PACK-MANIFEST.json` (304 files) to include Cargo.lock evidence and P0 evidence files. Alternative considered: cleaning target before each validate, but that would hide real determinism; exclusion is bounded, observable, and mirrors CI behavior where pack validation runs before builds.
  - **Impact**: `validate_pack` still fail-closed, just not polluted by ephemeral build outputs. No security/policy weakened.
- **deny.toml patched**: Added `allow-wildcard-paths = true` under `[bans]` to allow `workspace = true` internal path deps (publish=false crates) while retaining `wildcards = deny` for external crates. Considered alternatives: setting `wildcards = warn` (would silently allow external wildcards) or removing bans entirely (would weaken gate). Chosen fix is minimal and matches cargo-deny PR #487 intent for private crates. No new external dependency added.
- No ADR required: both changes are build-tool hygiene within P0 scope, not system-boundary changes. Recorded in `agent/DECISIONS.md` — no new ADR file.
