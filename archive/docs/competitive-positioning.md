# Competitive Positioning

Narrivy must not compete primarily on “number of ASR engines”. Multi-engine local dictation is becoming table stakes.

## Competitive axes to lead

1. **Linux-native reliability** — Wayland/compositor/input/output complexity handled automatically.
2. **Premium UX** — polished onboarding, feedback, diagnostics and recovery.
3. **Local-first context intelligence** — app/project/vocabulary-aware without opaque data collection.
4. **Developer and AI-agent workflows** — repository-aware Prompt/Developer modes.
5. **Adaptive compute** — route work across CPU/GPU/NPU based on latency, language, battery and model fit.
6. **Personal learning** — corrections, scoped vocabulary, style and routing improve over time.
7. **Portable platform architecture** — Linux first, not Linux trapped.
8. **Transparent privacy** — every pipeline stage knows and displays local/cloud boundaries.
