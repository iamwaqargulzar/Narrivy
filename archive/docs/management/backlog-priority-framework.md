# Backlog Priority Framework

Score proposed work on:
- Core reliability (0–5)
- Daily user value (0–5)
- Differentiation/moat (0–5)
- Accessibility impact (0–3)
- Privacy/security improvement (0–3)
- Cross-platform leverage (0–3)
- Engineering cost (negative 0–5)
- Long-term maintenance cost (negative 0–5)

P0 work protects reliability/security/architecture. P1 drives the core product and differentiation. P2 broadens workflows/platforms. P3 is exploratory/long-term.

Do not use the score mechanically; it is a forcing function for tradeoff discussions.
