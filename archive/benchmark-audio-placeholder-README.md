# Benchmark Audio Fixtures

Place the fixed synthetic fixtures described in `docs/maintainers/qualification/performance-benchmark-protocol.md` here.

- `fixture-short-en-4s.wav` — hash will be recorded in qualification evidence
- `fixture-long-en-30s.wav`
- etc.

Do not commit real user audio. Only synthetic/public fixtures belong here. Hashes are verified by `narrivy-qualify`.

Until real fixtures are generated, benchmarks operate in stub mode and P6 baselines are not yet passing.
