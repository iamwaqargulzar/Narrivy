guides, agent prompts, the v1.3 implementation plan, validation reports, and
licence-decision placeholders. They are superseded:
- **rules for agents:** `AGENTS.md`;
- **precedence:** `SOURCE_OF_TRUTH.md`;
- **the current plan:** `agent/completion-plan/README.md`;
- **scope:** `docs/product/vision-and-scope.md` and `BUILD_TARGET.json`;
- **licence:** MIT (`LICENSE`); the dependency policy is in `deny.toml`.

Several of these files give instructions that are now wrong (for example
"use scripts/run_gate.py" or "P0F is active"). Do not follow them.
