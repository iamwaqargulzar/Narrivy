# R14 — Ecosystem, Domain Packs, Teams & Companion/Compute (Post-1.0)

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

After core contracts stabilize, expose a versioned extension SDK (prefer sandboxed portable execution where practical), explicit permissions/provenance/signatures, validated domain packs containing vocabulary/pronunciations/Modes/snippets/templates/rules, optional team/shared precedence, authenticated encrypted compute-node transport under the same privacy policy, and a phone-as-microphone companion with QR/explicit pairing plus revoke/reset. Single-user offline Narrivy must remain fully functional without any ecosystem/team/companion service.
