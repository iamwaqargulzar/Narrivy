# R12 — Advanced Voice, Structured Workflows & Meetings (Post-1.0)

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

Only begin after Linux 1.0 release unless the owner explicitly changes `BUILD_TARGET.json`. Extend stable contracts with richer writing modes, smart templates/typed field navigation, schema-aware forms/JSON/tables, safe patch-based streaming insertion, Command/Hybrid/Spell/What-can-I-say/Voice Workflows/Anchored Dictation, long-running meeting capture, optional system audio, diarization, captions, TXT/Markdown/JSON/SRT/VTT export and optional local summaries. Every command/workflow remains typed/permissioned; meeting/media retention/privacy is explicit. Do not regress ordinary offline dictation.
