# Multilingual Model

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

Separate settings:
- spoken language(s);
- written language;
- script;
- translation target;
- locale/formatting convention.

Examples:
- Urdu + English speech → Urdu script + English.
- Urdu speech → Roman Urdu.
- Urdu speech → English translation.
- English speech → German.

Code-switching is a first-class task where backend support permits. Profiles can constrain candidate languages to improve accuracy.
