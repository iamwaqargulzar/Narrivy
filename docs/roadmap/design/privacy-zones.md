# Privacy Zones

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

A Privacy Zone is a high-priority rule matching an app/window/site/category where Narrivy behavior is constrained.

Actions can include:
- disable Narrivy;
- forbid surrounding/selected context;
- forbid history;
- forbid cloud;
- require local-only model;
- suppress learning;
- restrict actions.

Zones override Mode/Profile convenience settings.
