# GNOME Reference Adapter/Qualification

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

Ubuntu/GNOME Wayland is the second first-class Linux 1.0 environment.

P3–P6/P11 evidence must independently cover:

- GlobalShortcuts portal availability and activation/release semantics;
- permission UX/rebinding and denied/revoked permission behavior;
- PipeWire microphone capture, device switch/hotplug, suspend/resume;
- overlay focus/multi-monitor/scaling behavior;
- text-delivery route(s) for GTK, browser, VS Code/Electron, terminal, LibreOffice and representative XWayland target;
- Unicode/multiline/replace cases;
- package/daemon lifecycle under Ubuntu user session.

Do not infer GNOME behavior from COSMIC evidence. Capability outputs may legitimately differ while preserving the same domain API.
