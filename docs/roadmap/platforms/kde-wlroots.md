# KDE and wlroots Expansion

> **Status: roadmap / not in 1.0.** This describes a planned design, not current behaviour. See [the roadmap](../README.md).

Not a 1.0 blocker. Architecture must leave room for:
- KDE/KWin-specific text/shortcut capabilities;
- Fcitx-heavy environments;
- Sway/Hyprland/Niri and other wlroots-style compositor policies;
- compositor-provided shortcut bindings invoking Narrivy IPC.

Add each desktop only with an explicit compatibility test matrix and maintainership commitment.
