## Mission
P8 keeps only privacy/personalization essentials for a safe useful 1.0; advanced context, correction learning, project indexing, and fragile workflows are deferred unless proven low-risk.

## Required requirement IDs
`FUN-041`, `FUN-064`, `PRIV-001`, `PRIV-002`, `PRIV-003`, `PRIV-004`, `PRIV-005`, `PRIV-006`

## Execution
