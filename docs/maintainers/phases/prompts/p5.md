# Agent Work Order — P5 Production ASR, Model Manager & Compute Qualification

## Mission
P5 chooses one reference local ASR engine/runtime for 1.0, provides CPU correctness fallback, qualifies model/runtime/driver/hardware tuples, and handles model download/cache/offline lifecycle with Vulkan/GPU pool and NPU where qualified.

## Required requirement IDs
`FUN-003`, `FUN-028`, `FUN-029`, `PERF-005`, `PERF-007`, `PERF-008`, `PERF-009`, `PORT-006`, `SEC-002`, `TEST-005`

## Execution
1. Read `docs/maintainers/phases/phase-05-asr-compute.md`, `docs/architecture/speech/*`, `docs/architecture/compute-scheduler.md`, and resolved versions.
2. Choose one reference ASR engine/runtime for 1.0 (CPU fallback mandatory); integrate model registry, quant variants, and device qualification tuples.
3. Implement model download/hash/cache lifecycle plus `RuntimePackManager`; compiled artifact cache (Hot/Warm/Cold) with versioned invalidation + ownership/reference metadata; planner preference NPU→dGPU→iGPU→CPU with manual preferred/locked override and CPU correctness fallback.
4. Qualify on at least one native lane with fixed corpus, measuring accuracy/latency/RTF/memory; verify quant degradation vs baseline.
5. Verify CPU fallback, offline behavior, corrupt cache recovery, and Vulkan/GPU pool where present; emit evidence and pass gate.
