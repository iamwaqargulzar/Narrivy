# Support Matrix Policy

The published support matrix is generated from qualified evidence, not aspiration.

Use levels:
- **Supported:** tested in the release candidate on named environment/configuration.
- **Supported with fallback:** primary capability unavailable/unhealthy but a tested fallback provides the documented feature.
- **Experimental:** opt-in, not release-critical, known limitations listed.
- **Unknown/unqualified:** never marketed as supported.

Matrix dimensions include OS/desktop/session, CPU architecture, accelerator/runtime/model pair, trigger path, target-application classes, package type, and important accessibility/scaling cases.
