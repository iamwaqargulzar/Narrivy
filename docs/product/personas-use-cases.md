# Personas and Use Cases

## Primary launch personas

### Everyday Linux user
Wants reliable push-to-talk anywhere, clean punctuation, low setup burden, and offline operation.

### Developer / AI-agent user
Dictates technical terminology, file paths, code identifiers and long prompts into terminals, IDEs, ChatGPT-style tools, Codex/Claude/OpenCode-class agents. High value from project context and Prompt/Developer modes.

### Privacy-conscious professional
Wants local ASR and local post-processing, transparent context permissions, local history and optional self-hosted compute.

### Multilingual user
Needs mixed-language speech, independent spoken/written language, script choice, locale-aware formatting and custom vocabulary.

### Accessibility / reduced-keyboard user
Needs high reliability, alternate triggers, hands-free roadmap, robust recovery and visible status.

## Secondary/expansion personas
- writer/editor;
- student/researcher;
- journalist/interviewer;
- support representative;
- salesperson/CRM user;
- meeting-heavy professional;
- content creator/subtitle user;
- organization with private self-hosted inference.

## High-value use cases
1. Universal short-form dictation.
2. Long AI-agent prompts converted from rambling speech into structured instructions.
3. Code/project-aware terminology correction.
4. Email/message composition based on spoken intent.
5. Selected-text rewrite/translate/format.
6. Voice templates/snippets.
7. Voice notes captured into Inbox when no field is active.
8. Meeting transcription + action extraction.
9. Live captions and subtitle export.
10. Local-network inference from low-power laptop to powerful desktop.
11. Structured dictation to forms/tables/JSON.
12. Math/LaTeX dictation.
13. Anchored dictation while researching in another window.
14. Safe voice workflows and explicit command mode.
