# Critical User Journeys

Each journey must receive usability and automated coverage where feasible.

1. Install → first dictation.
2. Change microphone while idle.
3. Microphone disconnects during session.
4. Short message dictation into browser/chat.
5. Long prompt into AI coding agent.
6. Developer term corrected using project context.
7. Selected text → “make concise” → undo.
8. Text-delivery backend fails → automatic fallback.
9. Suspend/resume → shortcut still works.
10. No writable field → Inbox recovery.
11. Privacy Zone blocks cloud processing.
12. Model update/cache invalidation.
13. Reprocess old audio with a different model.
14. First meeting capture.
15. Diagnostic support bundle generation.
