# First-run Onboarding

Goal: first successful dictation without teaching the user ML terminology.

Flow:
1. Welcome + privacy summary.
2. Microphone permission/test.
3. Capability scan: desktop/session/shortcut/output/audio/compute.
4. Recommended processing profile and model download size.
5. Shortcut binding/test.
6. Dictation sandbox: user speaks, sees result, retries if needed.
7. Optional privacy/history choice.
8. “Narrivy is ready.”

Advanced setup is deferred.

On Linux, if the preferred shortcut/output path is unavailable, explain the fallback in human terms and offer a fix without asking the user to decode compositor jargon.
