# UI/UX Design Principles

1. **Invisible when working.** Narrivy mostly disappears during normal dictation.
2. **Simple by default.** Users choose outcomes, not inference runtimes.
3. **Power without clutter.** Advanced controls remain discoverable through progressive disclosure.
4. **Immediate feedback.** Shortcut acknowledgement and listening state must feel instant.
5. **Never steal focus.** Overlay is informational, not a competing app window.
6. **Recovery over blame.** Errors state what happened, what Narrivy did, and the next action.
7. **Undo is a product primitive.** AI edits/transformations are reversible.
8. **Privacy is visible.** Local/cloud and context use are understandable in the moment.
9. **Cross-platform identity, native respect.** Consistent Narrivy design language while respecting host accessibility/theme conventions.
10. **Accessibility is not a settings page.** It shapes every component.
