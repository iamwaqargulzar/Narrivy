# Model Lab / Benchmark Surface

This is an **advanced diagnostics surface**, not a default navigation requirement. It may live under Models & Hardware or Diagnostics.

It can run fixed non-private qualification audio, compare installed model/device combinations, show cold/warm load, latency, memory and accuracy summaries, and export privacy-safe benchmark metadata. It must not automatically record or retain the user's ordinary dictation for benchmarking.

Unsupported/unqualified combinations are labeled clearly. Benchmark results include build/runtime/model/device identity so comparisons remain meaningful.
