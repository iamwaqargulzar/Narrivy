# Success Metrics

## Product quality
- first-dictation success rate on supported desktops;
- text-delivery success rate by app/toolkit;
- sessions recovered after controlled failure injection;
- correction rate and repeated-correction rate;
- time-to-first-success during onboarding;
- support-report resolution rate.

## Performance
- P50/P95 hotkey→listening;
- P50/P95 speech→first partial;
- P50/P95 release→raw transcript;
- P50/P95 release→committed text;
- idle and active memory;
- model warmup/load times;
- laptop energy use by Performance Profile.

## User value
- weekly active dictation days;
- words/minutes dictated;
- percentage of sessions requiring manual repair;
- Mode/Profile adoption;
- repeat usage of Developer/Prompt/Compose;
- local vs cloud processing preference.

Do not optimize vanity word-count metrics at the expense of accuracy, privacy, or user autonomy.
