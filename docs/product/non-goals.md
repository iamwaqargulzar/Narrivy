# Non-goals and Scope Guards

For the initial product:
- Do not support every distro before Pop!_OS COSMIC is excellent (then Ubuntu GNOME, per the roadmap).
- Do not add ASR engines merely to increase a count.
- Do not build a generic autonomous desktop agent in Narrivy Core.
- Do not allow arbitrary shell commands through natural-language voice actions.
- Do not make cloud accounts mandatory.
- Do not require users to understand inference providers to succeed.
- Do not build mobile as a complete standalone product before desktop is mature; a microphone companion can come earlier.
- Do not build a plugin marketplace before extension contracts are stable.
- Do not add medical/legal claims without appropriate domain validation and product/legal review.
- Do not store sensitive context for “future AI usefulness” without an explicit user-visible purpose.
