# UX and Accessibility Testing

Automate what is stable, manually validate what is perceptual.

Checklist:
- keyboard-only flows;
- screen reader labels/live regions;
- 200% scaling;
- reduced motion;
- high contrast;
- dark/light/system theme;
- long translations and RTL text;
- error recovery without mouse;
- overlay does not steal focus;
- onboarding with fallback capabilities;
- no jargon in normal path.
