# ASR Evaluation

Benchmark suites should include:
- conversational English;
- fast speech;
- quiet/whisper speech;
- noisy speech;
- names/proper nouns;
- numbers/dates;
- technical/software terms;
- code-like identifiers;
- mixed languages;
- self-corrections;
- long utterances.

Metrics:
- WER/CER where appropriate;
- term accuracy;
- semantic error rate;
- latency;
- memory/energy;
- confidence calibration if exposed.

Do not optimize against one benchmark corpus only.
