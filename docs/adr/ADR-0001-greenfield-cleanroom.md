# ADR-0001: Greenfield clean-room implementation

- Status: Accepted
- Date: 2026-08-20

## Decision
Narrivy is implemented from original requirements and public platform specifications. Reference products are behavioral/competitive inputs only.

## Rationale
Avoids inherited coupling/branding/IP obligations and creates a coherent architecture owned by Narrivy.

## Consequences
Implementations that violate this decision require a superseding ADR.
