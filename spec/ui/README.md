# UI Specification Assets

The design system is token-driven. Do not lock brand colors/fonts in the architecture pack before the visual identity is intentionally designed.

Requirements:
- semantic tokens, never raw theme values scattered through feature CSS;
- WCAG-appropriate contrast and visible focus states;
- system/light/dark themes;
- reduced-motion token overrides;
- density/scaling resilient at 200%;
- overlay tokens separated from full-window component tokens.
